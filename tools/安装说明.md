# Python + rembg 安装说明

## 一键安装（推荐）

### 步骤

1. **双击运行安装脚本**
   - 打开文件夹 `tools\`
   - 双击 **"安装Python-简单版.bat"**（或运行 `install-python-rembg.ps1`）
   - 等待安装完成（约 5-10 分钟）

2. **安装过程**
   - 脚本会自动检测是否已安装 Python
   - 如果没有，会自动下载并安装 Python 3.11
   - 然后自动安装 rembg、pillow、onnxruntime
   - 首次安装会下载约 500MB 的 AI 模型文件

3. **重启应用**
   - 安装完成后，重启 "电商魔丸" 应用
   - 高精度抠图功能即可使用

---

## 手动安装（如果自动安装失败）

### 步骤1：安装 Python

1. 访问 https://www.python.org/downloads/
2. 下载 **Python 3.10 或更高版本**（推荐 3.11）
3. 运行安装程序
4. **重要**：勾选 "Add Python to PATH" 选项
5. 点击 "Install Now"

### 步骤2：安装 rembg

打开命令提示符（CMD）或 PowerShell，执行：

```bash
pip install rembg pillow onnxruntime
```

如果下载慢，可以使用国内镜像：

```bash
pip install rembg pillow onnxruntime -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 步骤3：验证安装

```bash
python --version
pip show rembg
```

## 常见问题

### 1. 提示 "pip 不是内部或外部命令"

Python 安装时没有勾选 "Add Python to PATH"。重新安装 Python 并勾选该选项。

### 2. 安装 rembg 时卡住或很慢

rembg 需要下载 AI 模型文件（约 500MB），首次安装较慢。请耐心等待，或使用国内镜像源。

### 3. 提示 "Microsoft Visual C++ 14.0 is required"

某些依赖需要编译工具，可以：
- 安装 Visual Studio Build Tools：https://visualstudio.microsoft.com/visual-cpp-build-tools/
- 或下载预编译的 rembg 版本

### 4. 安装完成后仍提示 "未检测到 Python"

重启电脑或重新打开命令提示符，让环境变量生效。
