# 电商魔丸（Fan Generator Desktop）

> 基于 Electron + React + TypeScript 的本地电商主图 / 详情图生产工具，当前版本 `4.9.0`。

## 1. 项目解决什么问题

电商运营在做主图、轮播图和详情页时，通常要反复完成同一套动作：导入商品图、去背景、按固定版式摆放、替换 PSD 占位层、生成不同背景、批量导出并整理文件名。商品一多，这些操作会占用大量时间，而且不同批次之间很难保持版式一致。

本项目把这条生产流程收进一个 Windows 桌面应用：

- 本地完成素材管理、画布排版、抠图和导出，不依赖在线设计平台。
- 用自由排版、背景轮换和套版模板，减少重复拖拽与重复排版的成本。
- 用 PSD 占位层和场景轮播模板，把一套成熟版式复用到不同商品上。
- 通过 OpenAI / OpenAI-compatible 接口生成场景图和详情图提示词，减少找背景、写提示词的时间。
- 项目可以保存为本地文件，并自动保存与恢复，避免做到一半丢失进度。

它不是“全自动生成成品图”的工具。抠图、AI 分析和自动排版负责提速，最终画面仍然可以在画布上手动调整。

## 2. 主要功能

| 模块 | 当前实际能力 |
| --- | --- |
| 项目管理 | 新建、打开、保存、另存为、最近项目、未保存状态提示、自动保存、异常退出后的启动恢复 |
| 画布 | 设置正方形画布尺寸；颜色背景、图片背景、PSD 背景 |
| 素材管理 | 批量导入图片、勾选素材、缩略图裁切/完整显示、素材预览、清空素材、批量缩放素材 |
| 自由排版 | 设置随机款数、同款数量、重复规则；居中/三角/两侧/竖排/网格五种风格；网格行列、间距、对齐；一键排版与重排；自由图层统一缩放 |
| 图层编辑 | 文字层、贴纸层、自定义插图；拖动、缩放、旋转、透明度、滤镜；上下移动与置顶置底；隐藏、锁定、复制、删除、拖动排序、多选 |
| 文字编辑 | 字体、颜色、字号、对齐、粗体、描边、阴影；双击画布中的文字可直接编辑 |
| PSD 套版 | 导入 PSD、设为背景、加入背景轮换、进入文档模式拆解图层；标记占位层和前景层；把素材绑定到占位槽位；批量替换占位层并导出 |
| 背景轮换 | 导入多张背景、切换当前背景、拖动排序、删除；保存、套用、删除背景轮换模板；支持把 PSD 加入轮换 |
| 套版模板 | 在轮换套版模式下按场景保存草稿，再把整套草稿保存成套版模板；支持套用、预览和删除模板 |
| 模板库管理 | 将背景轮换模板、套版模板、PSD 模板等打包导出为 JSON；从 JSON 导入模板库 |
| 智能抠图 | 快速去底 `edge-floodfill` 与高精度 `rembg-python` 两种 Provider；单张/批量抠图、重抠、还原、下载抠图结果、黑白蒙版 |
| AI 场景图 | 配置 OpenAI / OpenAI-compatible / Ollama；测试连接；生成 5 张场景图；上传参考图复刻场景；自动导入背景轮换；单品/多商品自动上场景 |
| AI 详情图 | 选择 10 类详情图、比例和数量；识别商品；分析商品并生成分类型提示词；两阶段“先分析、再出图”；上传参考详情图复刻风格；支持多尺寸与提示词预设 |
| 附件与装饰 | 内置促销 Emoji 装饰；上传自定义插图并作为图层加入画布 |
| 水印 | 文字水印或图片水印；九宫格位置、偏移、透明度、旋转、平铺间距；画布与导出同步生效 |
| 批量导出 | 导出当前画布单张 JPG；无套版模板时批量导出；按套版模板导出轮播图；PSD 批量套版导出；按每 N 张或每个产品分文件夹；文件前缀/后缀、使用图片名、随机组合标题；导出进度与取消 |
| 历史操作 | 撤销、重做、历史面板 |

### 当前实现边界

- 主界面当前开放的是“自由排版”和“轮换套版”两种排版模式；代码里仍保留其他布局引擎，但主界面没有对应的固定排版入口。
- `edge-floodfill` 是本地快速去底算法，适合白底、浅底和纯色底商品图，不等同于大模型精细分割；复杂毛发、透明材质和强反光边缘更适合 `rembg-python`。
- AI 出图只接入了 OpenAI / OpenAI-compatible 的 `/images/generations`。Ollama 可参与 AI 详情图中的商品识别和提示词分析，但当前不能通过 Ollama 直接生成图片。
- AI 详情图已经接通配置、商品识别、提示词分析和出图调用，但独立的结果浏览/批量下载页面尚未挂到主界面；生成结果暂存在应用状态中，现阶段没有界面内的完整结果画廊。
- 导出格式当前固定为 JPG，尚未提供 PNG/WebP 或多尺寸自动导出选项。
- Windows 打包目标为 x64 NSIS 安装包；源码中的其他平台构建未配置。

## 3. 安装方法

### 3.1 直接运行已打包的安装程序

源码包默认不包含安装包；如果你已经执行过打包，`release/` 目录中会有以下文件，可直接安装：

```text
release/电商魔丸-Setup-4.9.0.exe
```

双击安装后启动“电商魔丸”。当前 NSIS 配置为一键安装、按当前用户安装，不提供自定义安装目录。

### 3.2 从源码运行（开发模式）

推荐环境：

- Windows 10 / Windows 11 x64
- Node.js 20 LTS 或 22 LTS
- npm 10 及以上
- 首次安装依赖时需要能访问 npm 源和 Electron 二进制下载地址

先确认环境：

```bash
node -v
npm -v
```

进入项目目录并安装依赖：

```bash
cd fan-generator-desktop
npm install
```

启动桌面开发模式：

```bash
npm run dev
```

该命令会同时启动 Vite 开发服务器（`http://127.0.0.1:5173`）和 Electron 窗口。只启动前端页面可用：

```bash
npm run dev:web
```

注意：`dev:web` 只运行浏览器端 UI，文件选择、项目保存、抠图、AI 主进程代理等桌面能力不可用，不能替代 `npm run dev`。

常用脚本：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动 Vite + Electron 开发模式 |
| `npm run dev:web` | 只启动前端开发服务器 |
| `npm run build` | 构建前端和 Electron 主进程 |
| `npm run build:web` | 只构建前端到 `dist/` |
| `npm run build:electron` | 只编译 Electron 到 `dist-electron/` |
| `npm run dist:win` | 构建并生成 Windows x64 NSIS 安装包 |
| `npm run dist:portable` | 构建并生成 Windows 便携版 |
| `npm run dist:dir` | 只生成未打包的目录版，适合先验证运行 |

安装包默认输出到 `release/`：

```text
release/电商魔丸-Setup-4.9.0.exe
release/win-unpacked/
```

### 3.3 安装高精度抠图环境（可选）

快速去底 `edge-floodfill` 不依赖 Python，开箱可用。高精度抠图 `rembg-python` 需要本机安装 Python 和以下依赖：

```bash
pip install rembg pillow onnxruntime
```

建议使用 Python 3.10 及以上版本。应用会自动尝试 `py -3`、`python`、`python3` 以及 Windows 常见 Python 安装路径。如果 Python 不在常规位置，可在启动 Electron 前指定：

```powershell
$env:FAN_MATTING_PYTHON = "python"
npm run dev
```

`rembg` 第一次运行高精度模型时可能需要下载模型文件，首次抠图会明显变慢。

### 3.4 配置 AI 服务

AI 不需要额外安装本地服务，但需要在应用内的“AI助手”页配置：

- `OpenAI`：填写 API Key，使用 OpenAI 官方接口。
- `OpenAI-compatible`：填写兼容 `/chat/completions` 和 `/images/generations` 的 Base URL、模型、出图模型和 API Key。
- `Ollama`：默认地址 `http://127.0.0.1:11434`，示例模型 `qwen2.5:7b`；仅支持本地对话/看图，不支持本地出图。

API Key 由 Electron 主进程通过 `safeStorage`（Windows 下使用 DPAPI）加密后保存到应用配置目录。已保存的密钥不会回传渲染进程，渲染进程只接收“是否已配置”的状态；新输入的 Key 仅在保存时通过 IPC 交给主进程，带鉴权的 AI 请求也由主进程发出。API Key 不会写入项目文件或前端 `localStorage`，保存后不会在输入框中回显。

修改 Provider、Base URL、模型或 API Key 后，请先点击“保存配置”，再点击“测试连接”。连接测试与正式生成都使用主进程已保存的配置。

## 4. 使用方法

### 4.1 最短工作流：做一张单品主图

1. 启动应用，在顶栏确认当前项目状态；未保存时会显示“未保存”。
2. 在左侧“素材管理”点击“导入图片”，导入商品图并勾选要使用的素材。
3. 在“画布设置”中设置画布尺寸，选择颜色背景或导入背景图片。
4. 在“智能抠图”中选择快速去底或高精度去底，先处理白底商品图。
5. 在“排版方式”选择“自由排版”，设置随机款数和同款数量，点击“排版”。
6. 在“图层管理”添加文字层，输入标题；双击画布文字可直接修改。
7. 在右侧“导出设置”填写文件前缀，点击“导出当前画布（单张）”。

导出单张时，文件会写入所选目录下的 `<前缀>_preview/` 文件夹，文件名为 `<前缀>_current.jpg`。

### 4.2 项目新建、保存与恢复

- 顶栏“新建”：清空当前项目；有未保存修改时会先确认。
- 顶栏“保存”：首次保存会要求选择路径，之后覆盖保存到当前路径。
- 顶栏“另存为”：保存为新的项目文件。
- 顶栏“打开”：打开本地项目文件；有未保存修改时会先确认。
- 顶栏“最近项目”：快速打开最近使用过的项目。
- 项目文件是 JSON，包含 `version`、`savedAt` 和完整的 `appState`。
- 有未保存修改时，应用会延迟自动保存到用户数据目录；下次启动如果发现上次未正常关闭留下的自动保存内容，会提示是否恢复。

### 4.3 素材管理

- “导入图片”支持一次选择多张图片。
- 点击素材缩略图可切换勾选状态；素材区的全选框可全选/取消全选。
- “裁切填充”和“完整显示”控制缩略图显示方式，不改变原图。
- “预览”会在画布区域显示素材预览，点击“返回画布”回到编辑状态。
- “批量缩放素材”会把选中素材的默认缩放比例同步到画布中同源的自由图层。
- 清空素材会移除当前素材列表，请先保存项目或确认不再需要。

### 4.4 自由排版

切换到“排版方式”中的“自由排版”后，可以设置：

- 随机款数：一次参与排版的商品款数。
- 同款数量：每个商品重复出现的份数。
- 重复规则：`不重复` 或 `可重复`，影响组合队列。
- 排版风格：居中、三角、两侧、竖排、网格。
- 网格参数：列数、行数、间距、水平/垂直对齐，仅在选择网格风格时显示。

点击“排版”生成新的自由图层；点击“重排”会基于当前自由图层重新计算位置。改变随机款数或同款数量时，自由排版模式会自动重新排版。

如果画布中已有自由图层，可使用“统一缩放（设为平均尺寸）”把尺寸拉齐。

### 4.5 画布背景与背景轮换

“画布设置”提供三种背景类型：

- 颜色：选择底色。
- 图片：导入背景图；可一次加入多张形成轮换背景。
- PSD：导入 PSD 模板后作为背景使用。

图片背景轮换区支持：

- 点击缩略图切换当前背景。
- 拖动缩略图调整顺序。
- 删除单张背景。
- 清空全部轮换背景。
- 把当前轮换背景保存为背景模板，并在以后套用或删除。

保存的背景模板、套版模板和 PSD 模板可以在左侧“模板库管理”中导出为 JSON，或从 JSON 整体导入。导入模板库会替换当前模板数据，操作前会二次确认。

### 4.6 PSD 套版

1. 在“画布设置”把背景类型切到“PSD”。
2. 点击“导入 PSD”，可一次导入多个 PSD 文件。
3. 在下拉框选择模板，点击“设为背景”或“加入切换”。
4. 需要拆解可编辑图层时，点击“进入文档模式”，PSD 图层会拆到画布上。
5. 在图层管理中选中 PSD 图层，标记为“占位层”或“前景层”：
   - 占位层：批量套版时被素材替换。
   - 前景层：用于遮挡商品，保留在占位图之上。
6. 把素材拖到 PSD 产品层下方的“素材图层”区域，完成槽位绑定。
7. 勾选素材后点击“批量套用”，占位层会按素材顺序循环替换。
8. 需要先手动调整商品位置时，可开启“手动排版模式”；排好后点击“批量套用”或使用“PSD 批量套版导出”。

### 4.7 轮换套版与场景轮播模板

适合“5 张背景对应 5 种商品展示方式”的固定轮播风格：

1. 在“排版方式”切换到“轮换套版”。
2. 准备多张场景背景（图片或 PSD），切到第一张背景。
3. 把商品和文字排好，点击“保存当前场景”加入草稿。
4. 切换到下一张背景，重新排版并继续保存草稿。
5. 全部场景完成后点击“保存草稿为套版模板”。
6. 以后换新商品时，在“套版模板”下拉框选择模板，点击“套用”或“预览首张”。
7. 在“导出设置”点击“导出套版结果”。

导出时可以选择“每 N 张一个文件夹”或“每个产品独立文件夹”。如果当前勾选素材少于模板槽位，需要多选素材，或把重复规则切到“可重复”。

### 4.8 智能抠图

1. 在素材区勾选要处理的商品图。
2. 打开“智能抠图”，选择抠图方式。
3. `快速去底` 参数：
   - 背景判断：自动 / 偏白背景 / 偏深背景。
   - 背景容差：数值越高去底越激进，白底商品图建议从 32-42 开始。
4. `高精度（Python / rembg）` 参数：
   - 模型：`u2netp`（推荐，轻量快速）、`isnet-general-use`、`u2net`、`u2net_human_seg`、`u2net_cloth_seg`。
   - `alpha matting`：精修边缘。
   - 前景阈值 / 背景阈值 / 腐蚀尺寸：用于控制边缘保留与残底。
5. 勾选“同时输出黑白蒙版”可额外生成蒙版。
6. 在左侧“批量抠图”区域点击“抠已选素材”；如果全部已抠图，按钮会变为重抠。
7. 抠图结果会自动回填素材预览和画布中同源图片图层。
8. 可点击“还原”恢复原图，或点击“下载”导出已处理结果。

快速去底适合纯色背景；复杂边缘、透明材质和毛发建议使用 `rembg-python`。

### 4.9 AI 场景图

1. 先在“AI助手”页配置 Provider、Base URL、对话模型、出图模型、API Key 和温度，并点击“测试连接”。
2. 在“AI 场景图”填写场景需求、构图/留白，选择输出尺寸。
3. 点击“生成 5 张场景图”，结果会自动导入背景轮换。
4. 也可以点击“选择参考图”，上传一张喜欢的场景图，再点击“复刻场景”生成同风格变体。
5. 点击生成结果缩略图切换当前背景。
6. 勾选商品素材后，点击“单品自动上场景”或“多商品上场景”，应用会按场景预设把商品摆到背景中。
7. 继续补文字、贴纸、水印，然后导出。

出图能力依赖 OpenAI / OpenAI-compatible 的 `/images/generations`。Ollama 不能直接出图。

### 4.10 AI 详情图

AI 详情图与“AI助手”共用模型配置，使用前请先在“AI助手”页完成 API Key 和模型设置。

1. 切换到右侧“AI详情图”页。
2. 选择生成模式：`常规生成` 或 `复刻详情`。
3. 选择图像类型并设置每类数量。当前支持：主图、痛点/卖点图、功能/结构图、尺寸规格图、场景结果图、差异化价值图、对比优势图、A+ 收束图、核价场景图 A、核价场景图 B。
4. 选择比例（1:1、4:5、3:4、16:9、9:16）和数量；勾选“一键多尺寸”可对选中比例各出一张。
5. 在素材区勾选商品图片，填写产品名、卖点、文案风格、补充要求；可点击“拍照识别商品”让视觉模型识别商品信息。
6. 点击“分析商品并生成提示词”，分析完成后点击生成按钮批量出图。
7. 复刻模式下，先上传参考详情图，再执行分析和生成；应用会先分析参考图风格，再生成对应提示词。
8. “高级设置”可设置国家/语言、商品模式、限制条件；提示词模板支持英文专业版、中文简洁版和自定义编辑。

当前限制：详情图生成结果保存在应用状态中，独立的结果浏览页尚未挂载到主界面，暂时不能像主画布导出那样直接在界面里浏览和批量下载全部结果。

### 4.11 图层、文字与装饰

- “文字图层”新增一个文字层；“贴纸”导入图片作为自由图层。
- “附件插图”提供促销 Emoji 和自定义插图，点击即可加入画布。
- 图层面板支持拖动排序、显示/隐藏、锁定、复制、删除、多选和上下移动。
- 选中文字层后可调整字体、颜色、字号、对齐、粗体、描边和阴影。
- 选中图片层后可调整亮度、对比度、饱和度和色相；可设置透明度。
- 画布中拖动图层改变位置，右下角手柄缩放，上方手柄旋转。
- 双击文字图层可直接在画布上编辑文字。

常用快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 |
| `Delete` / `Backspace` | 删除当前图层（输入框内不会触发） |
| `Ctrl/Cmd + 点击图层` | 多选图层 |

### 4.12 水印

在“画布设置”下方的水印面板中：

1. 勾选“启用水印”。
2. 选择文字水印或图片水印。
3. 设置文字、字号、颜色，或上传水印图片和图片大小。
4. 设置九宫格位置、X/Y 偏移、透明度、旋转。
5. 需要满屏平铺时开启平铺模式并设置间距。

水印会同时作用于画布预览和导出结果。

### 4.13 导出

“导出设置”支持：

- 文件前缀、文件名后缀。
- “使用图片名作为文件名前缀”。
- 导出当前画布（单张 JPG）。
- 无套版模板时批量导出。
- 选中套版模板时导出套版结果。
- PSD 占位层存在时执行 PSD 批量套版导出。
- 每 N 张一个文件夹，或每个产品独立文件夹。
- 随机组合标题：设置必含词、随机词库、是否把必含词放最前、是否包含图片名。
- 导出进度显示、取消导出和完成后关闭进度。

导出前请先选择输出根目录。批量导出会在根目录下按当前规则创建子文件夹。

## 常见问题

**`npm install` 卡在 Electron 下载**

确认网络可以访问 Electron 二进制下载地址，或为 npm/Electron 配置可用镜像后重新安装。

**高精度抠图显示不可用**

确认已安装 Python、`rembg`、`pillow`、`onnxruntime`，然后在抠图面板点击“重新检测环境”。必要时用 `FAN_MATTING_PYTHON` 指定 Python 路径。

**AI 测试连接失败**

检查 Base URL、模型名、API Key 和网络。OpenAI-compatible 服务必须兼容 `/chat/completions`；生成场景图还要求兼容 `/images/generations`。

**批量导出没有图片**

检查是否已勾选素材、画布中是否存在可导出的图层、套版模板槽位是否满足，以及是否选择了输出目录。套版模板导出时，素材数量不足需要多选素材或开启“可重复”。

**打包后安装包在哪里**

执行 `npm run dist:win` 后查看 `release/`，默认产物为 `电商魔丸-Setup-4.9.0.exe`。
